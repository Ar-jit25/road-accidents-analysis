This project is a **Streamlit Dashboard** that analyzes road accident data in India.  
It provides interactive visualizations to explore accident patterns based on factors like vehicle type, area, weather conditions, day of the week, casualties, and more.

---

## 📂 Project Structure
ROAD-ACCIDENTS-ANALYSIS/
│
├── data/
│ └── RTA Dataset.csv # Dataset used in the project
├── app.py # Main Streamlit app
├── dashboard.py # Additional dashboard version
├── requirements.txt # Python dependencies
└── README.md # Project documentation



---

## ⚙️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/road-accidents-analysis.git
cd road-accidents-analysis
```
### 2. Create virtual environment (optional but recommended)

# Windows
```bash
python -m venv venv
venv\Scripts\activate

# Mac/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```
### 4. Run the Streamlit preview

```bash
streamlit run app.py
```

## Features

Show raw dataset preview
Visualize accidents by vehicle type
Analyze accidents by area (Urban/Rural)
Accidents vs road surface conditions
Accidents vs weather conditions
Distribution by day of the week
Casualties by vehicle type
Accidents by light conditions
Heatmap: Road Surface vs Weather
